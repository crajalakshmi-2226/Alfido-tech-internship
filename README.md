## Task 1 - Breast Cancer Classification

### Objective
Build and evaluate machine learning models for breast cancer classification.

### Dataset
Breast Cancer Wisconsin Dataset available through Scikit-learn.

### Models Used
- Logistic Regression
- Random Forest Classifier

### Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC
- 5-Fold Cross-Validation

### Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Google Colab

### How to Run
1. Open the `.ipynb` notebook in Google Colab.
2. Run the cells in order from top to bottom.
3. The notebook trains both models and displays evaluation results and confusion matrices.
